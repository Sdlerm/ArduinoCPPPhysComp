# ArduinoCPPPhysComp

Physical computing projects built with Arduino IDE C++.

## Getting started

This repository is set up as an Arduino sketch project. To open it in Arduino IDE:

1. Open Arduino IDE.
2. Select **File > Open**.
3. Open the `ArduinoCPPPhysComp` folder and select `ArduinoCPPPhysComp.ino`.
4. Select your board and port, then upload.

The included sketch is a simple LED blink starter using `LED_BUILTIN`.

## Project structure

- `ArduinoCPPPhysComp.ino` - starter sketch for the repository

Add new physical computing experiments by expanding this sketch or adding additional sketch folders as the repository grows.
